# คู่มือการจัดการสาขาและข้อมูลเครื่องมือ (Branch & Equipment Setup Guide)

เอกสารนี้อธิบายขั้นตอนการเพิ่มสาขาของศูนย์เครื่องมือใหม่ๆ และการกำหนดสาขาให้กับเครื่องมือวิทยาศาสตร์ เพื่อให้แสดงผลในหน้า `services.html` ได้อย่างถูกต้อง

## 1. การเพิ่มหรือแก้ไขสาขา (Branches)

รายชื่อสาขาจะถูกตั้งค่าไว้ที่ตัวแปร `branchConfig` ในไฟล์ `data.js`

### ขั้นตอนการเพิ่มสาขาใหม่:
1. เปิดไฟล์ `data.js` 
2. เลื่อนลงมาที่ส่วนของ `// ===== BRANCH CONFIG =====` (ประมาณบรรทัดที่ 480)
3. เพิ่มข้อมูลสาขาใหม่ในอ็อบเจกต์ `branchConfig` โดยใช้รูปแบบ `"รหัสสาขา": { name: "ชื่อที่แสดง", color: "รหัสสี" }`

**ตัวอย่างโค้ด:**
```javascript
const branchConfig = {
  "salaya": { name: "MU-FRF", color: "#2563eb" },
  "muka": { name: "MUKA", color: "#059669" },
  "musc": { name: "MUSC", color: "#db2777" },
  
  // การเพิ่มสาขาใหม่:
  "new_branch": { name: "ชื่อสาขาใหม่", color: "#f59e0b" }
};
```

## 2. การเพิ่มเครื่องมือและกำหนดสาขา (Equipment)

เมื่อมีเครื่องมือวิทยาศาสตร์เข้ามาใหม่ หรือต้องการระบุว่าเครื่องมือชิ้นไหนอยู่สาขาใด สามารถทำได้โดยการเพิ่ม/แก้ไขข้อมูลในตัวแปร `equipmentData` (ในไฟล์ `data.js`)

### ขั้นตอน:
1. เปิดไฟล์ `data.js`
2. ค้นหาส่วน `// ===== EQUIPMENT DATA =====` ซึ่งเป็นลิสต์ข้อมูลเครื่องมือทั้งหมด
3. ในข้อมูลเครื่องมือชิ้นที่คุณต้องการระบุสาขา ให้เพิ่มตัวแปร (property) ชื่อ `branch: "รหัสสาขา"` เข้าไป (โดยรหัสสาขาต้องพิมพ์ให้ตรงกับที่ตั้งไว้ใน `branchConfig` เช่น `"muka"`)
4. **ข้อควรระวัง:** สำหรับเครื่องมือใดๆ ที่ **ไม่ได้ใส่ค่า branch เอาไว้** ระบบจะถือว่าเครื่องมือนั้นอยู่ที่สาขาเริ่มต้น (สาขา `salaya`) โดยอัตโนมัติ

**ตัวอย่างโค้ด:**
```javascript
const equipmentData = [
  { 
    id: 101, 
    groupId: 1, 
    nameTh: "เครื่องมือวิเคราะห์รุ่นใหม่", 
    nameEn: "New Analyzer",
    
    branch: "muka", // <--- กำหนดรหัสสาขาให้ตรงกับที่มีใน branchConfig
    
    brand: "Thermo", 
    descTh: "รายละเอียดเครื่องมือภาษาไทย...",
    // ... ข้อมูลอื่นๆ
  }
];
```

## 3. การแสดงผล
- หลังจากแก้ไขข้อมูลในไฟล์ `data.js` แล้ว ให้ **บันทึก (Save)** ไฟล์
- รีเฟรชหน้าเว็บ `services.html` บนเบราว์เซอร์
- ระบบจะสร้างปุ่มสำหรับเลือก "สาขา" ให้ใหม่โดยอัตโนมัติ และเมื่อผู้ใช้งานคลิกปุ่มสาขานั้นๆ รายการเครื่องมือก็จะถูกกรองมาแสดงเฉพาะเครื่องมือที่ถูกตั้งค่า `branch` เอาไว้ตรงกัน
