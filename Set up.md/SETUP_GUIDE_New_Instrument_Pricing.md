# คู่มือการเพิ่มเครื่องมือวิทยาศาสตร์ชิ้นใหม่ และอัตราค่าบริการใหม่

หากคุณมี **เครื่องมือวิทยาศาสตร์ชิ้นใหม่** เข้ามาพร้อมกับ **อัตราค่าบริการใหม่** สิ่งที่คุณต้องทำคือการอัปเดตข้อมูลในไฟล์ `data.js` ใน 2 จุดหลักๆ ครับ คือ 
1. `serviceData` (สำหรับเพิ่มอัตราค่าบริการ) 
2. `equipmentData` (สำหรับเพิ่มข้อมูลเครื่องมือ)

เพื่อให้ปุ่ม "ดูอัตราค่าบริการ" ในหน้ารายละเอียดเครื่องมือลิงก์ข้อมูลหากันได้ถูกต้อง หัวใจสำคัญคือต้องให้ **รหัสค่าบริการ (`code`)** ตรงกันครับ

---

## สมมติสถานการณ์ตัวอย่าง
คุณได้ "เครื่องปั่นเหวี่ยง (Centrifuge)" ตัวใหม่มา ให้บริการในกลุ่ม Bioscience รหัสบริการคือ `BS99-1A` และมีค่าบริการสำหรับ ม.มหิดล 100 บาท, รัฐบาล 150 บาท, เอกชน 200 บาท ต่อชั่วโมง

### ขั้นตอนที่ 1: เพิ่มอัตราค่าบริการ (ใน `serviceData`)
เปิดไฟล์ `data.js` เลื่อนไปที่ส่วนของ `const serviceData = [ ... ]` แล้วเพิ่มชุดข้อมูลนี้เข้าไป (สามารถแทรกไว้ท้ายกลุ่ม หรือต่อท้ายสุดก่อนวงเล็บปิด `];` ก็ได้)

```javascript
  { 
    group: "Bioscience instrument", 
    instrument: "Centrifuge", 
    code: "BS99-1A", // <--- รหัสนี้สำคัญมาก ต้องจำไปใส่ให้ตรงกันในข้อมูลเครื่องมือ
    mode: "High-Speed Centrifuge (Instrument use)", 
    unit: "hour", 
    mahidol: 100, 
    gov: 150, 
    priv: 200 
  },
```

> **ข้อแนะนำ:** หากเครื่องมือตัวนี้มีรูปแบบบริการหลายโหมด เช่น มีบริการวิเคราะห์ข้อมูลด้วย ก็เพิ่มข้อมูลอีกชุด `{...}` พร้อมรหัสใหม่เช่น `BS99-1B` ต่อท้ายลงไปได้เลย

---

### ขั้นตอนที่ 2: เพิ่มรายละเอียดเครื่องมือ (ใน `equipmentData`)
ในไฟล์ `data.js` เลื่อนลงมาที่ส่วนของ `const equipmentData = [ ... ]` แล้วเพิ่มข้อมูลเครื่องมือชิ้นใหม่เข้าไปดังนี้ครับ:

```javascript
  { 
    id: 999, // ตั้ง ID ให้เป็นตัวเลขที่ไม่ซ้ำกับเครื่องมืออื่นที่มีอยู่
    groupId: 1, // อิงตามกลุ่มเครื่องมือ (1 = Bioscience)
    order: "1.99", // ลำดับการเรียงบนหน้าเว็บ (ตัวเลขน้อยจะอยู่ด้านหน้า)
    nameTh: "เครื่องปั่นเหวี่ยงความเร็วสูง", 
    nameEn: "High-Speed Centrifuge", 
    brand: "Eppendorf/5430R", 
    qty: 1, 
    
    testCodes: "BS99-1A", // <--- ใส่รหัสค่าบริการให้ตรงกับ Step 1 เพื่อเชื่อมโยงปุ่มกด

    descTh: "เครื่องปั่นเหวี่ยงความเร็วสูงพร้อมระบบทำความเย็น เหมาะสำหรับการปั่นแยกสารชีวโมเลกุล", 
    descEn: "High-speed refrigerated centrifuge for biomolecular separation.",
    branch: "salaya", // (ตัวเลือก) ระบุสาขา ถ้าไม่ระบุจะเป็น salaya อัตโนมัติ
    domainTags: ["molecular_bio", "cell_bio"], // สาขาวิจัยที่เกี่ยวข้อง
    specs: "Max speed 30,000 xg; Temp -11 to 40°C" 
  },
```

> **ข้อแนะนำ:** หากเครื่องมือนี้ใช้กับบริการหลายรหัส สามารถใส่ลูกน้ำคั่นใน `testCodes` ได้เลย เช่น `"BS99-1A, BS99-1B"` ระบบจะนำรหัสตัวแรก (`BS99-1A`) ไปใช้สำหรับปุ่ม "ดูอัตราค่าบริการ" ครับ

---

### สรุปผลลัพธ์
เมื่อบันทึกไฟล์และรีเฟรชหน้าเว็บ:
1. เครื่องมือ "เครื่องปั่นเหวี่ยงความเร็วสูง" จะไปแสดงผลในหน้ารายชื่อเครื่องมือ (`services.html`)
2. ค่าบริการของเครื่องมือนี้จะไปแสดงผลในตารางอัตราค่าบริการ (`pricing.html`)
3. เมื่อผู้ใช้งานคลิกดูรายละเอียดเครื่องมือนี้บนหน้าเว็บ แล้วกดปุ่ม **"ดูอัตราค่าบริการ"** ระบบจะลิงก์ไปที่ `pricing.html?q=BS99-1A` และค้นหาพร้อมทำไฮไลต์บรรทัดค่าบริการที่มีรหัส BS99-1A ให้ทันที
